# `joyarm/` 架构设计

> 角色：软件/系统架构师。本文档为**架构定稿**：模块边界、依赖与关键接口；不写实现，按章节落地。

## 0. 命名约定（全仓库强制）

- **类名 = 驼峰（PascalCase）；文件名 = 小写 snake_case。**
- 设备三概念：`Mas`（多轴本体，不含末端）/ `End`（末端执行器）/ `Arm`（= Mas + End 完整臂）。
- Backend 三层（`Backend` 前缀）：根 `Backend` → 类型层 `BackendMas`/`BackendEnd` → 型号层 `BackendMasRebotDM`/`BackendEndJoyGripper`。
- 形参/属性：本体后端 `backend_mas`、末端后端 `backend_end`；robotics/safety 形参 `mas`，依赖 `MasProtocol`。
- 约定针对系统组件；项目品牌名 `joyarm`/`joyarm_code` 不改。

## 一、设计原则与编码约定

| 原则 | 落地 |
|:--|:--|
| **双包分层** | 核心 `joyarm/`（ROS2-free）+ 兄弟包 `joyarm_ros2/`（rclpy） |
| **设备三概念** | `Mas`（本体）→ `Arm(Mas)` 组合 `End`；`arm.fkine()` 继承自 Mas，`arm.end.open()` 操作末端 |
| **Backend 三层** | `Backend` → `BackendMas/BackendEnd` → 具体型号；按硬件类型、再按型号派生 |
| **单向导入、无环** | `arms` import `robotics/safety/backends`；`robotics/safety` **不 import `arms`**，只依赖 `utils.MasProtocol`（依赖倒置） |
| **backend 由 yaml 驱动** | 子类绑 backend **类**（`backend_mas_cls`/`backend_end_cls`），基类按 `configs/<model>.yaml` 的 `backend_mas`/`backend_end` 段实例化 |
| **离线模式** | 默认 `connected=False`（计算类可用）；`arm.connect()` 后才可 `get_state`/`command` |
| **算法默认 pinocchio** | robotics 不带 `method` 参数，默认 urdf+pin；手写实现请在 `Mas` 子类覆盖 |
| **形状重载 / 共享类型单定义 / 核心轻依赖 / 渐进式落地** | 同前 |

编码约定：`q=(n,)`/`(N,n)`、`T=(4,4)`；角度弧度；FK/IK 返回 numpy（进阶 `rep="se3"`）；软/硬限位分级；`ControlMode` 四态（POSITION/VELOCITY/TORQUE/MIT）。可视化不在核心包（rviz2 在 `joyarm_ros2`）。

## 二、分层与目录

```
        joyarm_ros2/  （兄弟包，依赖 joyarm + rclpy）
              ↓ 依赖
   ┌──────────────────────────────────────────────┐
   │  arms/      设备模型：Mas · End · Arm(Mas+End) · joyarm_rebot_dm  ← arm.xx
   ├──────────────────────────────────────────────┤
   │  robotics/  算法    safety/  安全              │
   │  backends/  通信（三层 Backend）               │ ← 仅依赖 utils + MasProtocol
   ├──────────────────────────────────────────────┤
   │  utils/     types · transforms · interfaces(MasProtocol) │
   └──────────────────────────────────────────────┘
      robots/  configs/   ← 数据/资产，由 arms 运行期加载
```

│   ├── backend_end.py          # BackendEnd(Backend)
│   ├── backend_mas_rebot_dm.py # BackendMasRebotDM(BackendMas)
│   └── backend_end_joygripper.py # BackendEndJoyGripper(BackendEnd)

## 三、核心包模块

### utils/【Ch2】
`types.py`（数据类/枚举/`clamp_to_limits`）、`transforms.py`（SO(3)/SE(3)）、`interfaces.py`（`MasProtocol`：`model/data/n/T_base/ee_frame_id/joint_limits(_soft)/tcp_limits/frame_placement`——robotics/safety 依赖它，不 import arms）。

### configs/【Ch2/7】
`configs/<model>.yaml`，按 backend 分段：
```yaml
backend_mas: {can_interface: can0, baudrate: 1000000, motor_ids: [1,2,3,4,5,6]}
backend_end: {can_interface: can0, baudrate: 1000000, id: 7}
```
（另含 urdf/ee_frame/q_home/mdh/joint_limits/tcp_limits。）未装 PyYAML 时回退类常量。

### backends/ —— 三层【Ch6/Ch13】
- `Backend`（根）：`connect/disconnect/read_state`。
- `BackendMas`：+ `enable/disable`、`send_position/velocity/torque/mit`、`set_zero/scan`、`read_state()->ArmState`。
- `BackendEnd`：+ `send_position/send_force/send_action`、`read_state()->dict`。
- 型号层：`BackendMasRebotDM(BackendMas)`、`BackendEndJoyGripper(BackendEnd)`（均占位）。

### arms/ —— 设备模型【Ch2/Ch13】
- `Mas`：本体基类。绑 `backend_mas_cls`，`__init__` 按 `backend_mas` 段实例化 `backend_mas`；门面 `fkine/ikine/jac/fdyn/idyn/mass_matrix/.../check_*_limits`（薄委托 robotics/safety，默认 pin）；`get_state/command`（连后可用）。
- `End`：末端基类。`__init__(backend_cls, backend_params)` 实例化 `backend_end`；`open/close/set_position/set_force/get_state`。
- `Arm(Mas)`：完整臂。绑 `backend_end_cls`，`__init__` 组合 `self.end = End(...)`（按 `backend_end` 段）；`connect()` 连本体+末端。
- `JoyArmRebotDM(Arm)`：绑 `backend_mas_cls=BackendMasRebotDM`、`backend_end_cls=BackendEndJoyGripper`；加载 config。

### robotics/【Ch3-9】
模块级函数，形参 `mas`（按 `MasProtocol` 访问），仅依赖 utils，不 import arms。默认 pinocchio，**无 `method` 参数**。fkine/ikine/jacobian/trajectory/dyn/control。

### safety/【Ch11】
形参 `mas` + `ArmState`，按 `MasProtocol` 访问，不 import arms。三层：关节/末端/整机。

## 四、ROS2 兄弟包 `joyarm_ros2/`
依赖 joyarm + rclpy。`arm_nodes/`（机器人→ROS2 node，Ch10）、`apps/`（teleop/vision/UI，rviz2 可视化）。

## 五、依赖关系
```
arms → utils, backends, robotics, safety（门面委托）；运行期加载 robots/configs
robotics / safety → utils（MasProtocol）；不 import arms
backends → utils（types）
utils → numpy
[joyarm_ros2] arm_nodes/apps → joyarm, rclpy
```

## 六、库边界与落地
SDK（`arm.xx`）→ `joyarm/`；ROS2 → `joyarm_ros2/`；CLI/GUI/任务编排 → `joyarm_code/quickstart/`；教学脚本 → `joyarm_code/chapt/`。
✅ Ch2 即用：utils/transforms+types+interfaces、backends 三层、arms/{mas,end,arm,joyarm_rebot_dm}、configs、robotics/fkine。
🟡 Ch3+ 占位：robotics/{ikine,jacobian,trajectory,dyn,control}、safety、backends 型号层、joyarm_ros2。
依赖：`numpy`、`pin`、`pyyaml`（核心）；`rclpy`（仅 joyarm_ros2）。
