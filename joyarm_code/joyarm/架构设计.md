# `joyarm/` 全篇架构设计方案（第 2~15 章）

> 角色：软件/系统架构师。本文档为**架构定稿**：仅确定模块边界、接口签名与依赖关系，**不写业务实现**，业务代码按章节顺序逐步落地（见末节落地优先级）。

---

## 一、设计原则与编码约定

| 原则 | 落地体现 |
|:--|:--|
| **分层解耦** | `utils`（基础）→ `arm`（设备模型）→ `robotics`（算法）→ `safety` → `backends`（通信）→ `application`（上层）；仅向下依赖 |
| **库 = SDK，被调用** | `joyarm` 只提供可复用库能力；CLI/GUI/任务编排等前端移入 `joyarm_code/quickstart/`（见 §库边界） |
| **`Arm` 作组合根** | `Arm` 持有 `model` + `backend`（可选）+ 限位，被 Ch5~Ch14 上层引用 |
| **Backend 仅真机** | `ArmBackend`/`EndBackend` 两条独立抽象，**不设物理仿真后端**；仿真/预演/教学走 `Arm(backend=None)` 离线模式 + meshcat 可视化 |
| **型号↔通信正交** | 型号 = `Arm` 子类（URDF/限位/home）；通信 = backend 实例；在 `load_arm(model=, backend=)` 正交组合 |
| **method 双版本** | fkine/ikine/jacobian/dyn 单函数 + `method` 参数：`'auto'`=pinocchio 黑盒（应用版）/ `'manual'`=手写白盒（原理版，先占位） |
| **形状重载** | `fkine` 等按输入形状自动切批量/非批量，无单独 `*_batch` 函数 |
| **共享类型只定义一次** | `Wrench/Twist/Pose/ArmState` 等集中在 `utils/types.py`，杜绝各模块重复 |
| **核心轻依赖** | `utils` 仅 numpy+stdlib；ROS2/PySide6/VLM/VR 等重依赖只进 `application/` 适配器 |
| **函数式为主** | 求解器为模块级函数；类（Arm/JoyArm/Gripper/Sensor）作载体 + 薄委托 |
| **渐进式落地** | 每模块标 Ch2.2 即用 / ChN 规划；占位用 `raise NotImplementedError("ChN 实现")` |
| **零状态污染** | 模块级函数无全局可变状态；`Arm` 仅持有 `model`/`data` |

**编码约定**：

- **离线模式语义**：`backend=None` 时计算类方法（fkine/jac/frame_placement/dyn/trajectory）可用，执行类方法（`command`/`get_state`）`raise RuntimeError("离线模式不可执行")`。这是 Ch2.2 工作空间场景无硬件即跑的前提。
- numpy shape：`q`=`(n,)`/`(N,n)`；`T`=`(4,4)`；批量 `T`=`(N,4,4)`；`Wrench/Twist` 内部 6 向量。
- 角度一律**弧度**（GUI 展示需度时由调用方转换）。
- FK/IK 返回 **numpy**（非 `pin.SE3`），降低门槛；进阶 `rep="se3"` 取原始对象。
- 公开 API 用中文 docstring，注明参数/返回 shape、单位、对应章节。
- 错误处理：URDF 缺失/帧名找不到/超限位/离线执行 → 明确异常（`ValueError`/`RuntimeError`）+ 定位信息。
- **软/硬限位分级**：`Arm.joint_limits_soft`（软，略窄留余量，供 `rand_q/clamp_q/is_q_valid` 裁剪，违规→`SafetyAction.CLAMP`）；`Arm.joint_limits`（硬，URDF/电机物理极限，供 `safety.joint_limits_check` 监测，违规→`Severity.ERROR/CRITICAL`）。二者协同构成 Ch11 多层防护。
- **控制模式**：`ControlMode` 四态——POSITION(`q`)/VELOCITY(`dq`)/TORQUE(`tau`)/**MIT**(`q,dq,tau_ff,kp,kd`，`τ=kp·(q_des−q)+kd·(dq_des−dq)+tau_ff`)；`command` 按 mode 取参，多余忽略。

## 三、`utils/` —— 基础层

> 仅依赖 numpy + stdlib，零机器人学耦合，可被任意上层/教学脚本复用。

### `types.py` —— 共享数据类型【Ch2.2 即用】

**枚举**：

| 枚举 | 取值 | 用途 |
|:--|:--|:--|
| `ControlMode` | `POSITION / VELOCITY / TORQUE / MIT` | Ch6 控制模式 |
| `Severity` | `INFO / WARNING / ERROR / CRITICAL` | Ch11 安全违规分级 |
| `SafetyAction` | `NONE / CLAMP / DAMPING_HOLD / FREEZE / ESTOP` | Ch11 响应策略 |
| `TrajectorySpace` | `JOINT / CARTESIAN` | Ch5 轨迹空间标识 |

**数据类（`@dataclass`）**：

| 类 | 字段 | 用途 |
|:--|:--|:--|
| `Wrench` | `force, torque: ndarray(3,)` | Ch9 力控、Ch11 TcpState、Ch12 共用 |
| `Twist` | `linear, angular: ndarray(3,)` | Ch4 速度、Ch12 笛卡尔遥操 |
| `Pose` | `T: ndarray(4,4)`（或 `R, p` 分量） | 统一位姿表示 |
| `JointState` | `q, dq, ddq, tau: ndarray(n,)`；`status: ndarray[int](n,)`；`temp_coil, temp_driver: ndarray(n,)`；`voltage, current: float` | Ch11.1 关节层；`status`=电机状态码（0=失能，1=使能，其他=过温/过流/通信等） |
| `TcpState` | `pose: Pose`, `twist: Twist`, `wrench: Wrench` | Ch11.2 末端层 |
| `ArmState` | `joint: JointState`, `tcp: TcpState`, `mode: ControlMode`, `timestamp: float`, `errors: list` | Ch11 聚合快照，监控器/示教/力控都消费它 |
| `JointLimits` | `q_min/max, dq_max, ddq_max, tau_max, temp_coil_max, temp_driver_max, voltage_min/max, current_max: ndarray(n,)` | Ch11.1 限位声明；实例化为 `Arm.joint_limits`（硬）/ `Arm.joint_limits_soft`（软，见编码约定） |
| `TcpLimits` | `workspace_box: ndarray(3,2)`, `v_lin_max, v_ang_max, f_max, t_max: float` | Ch11.2 末端限位 |
| `Violation` | `layer, joint_idx, metric, value, limit, severity` | Ch11 监控器输出；`layer` 标关节/末端/整机 |
| `IKResult` | `q, success, err, n_iter` | Ch3 逆解结果 |
| `ComplianceParams` | `K, D, M`（6×6 笛卡尔，默认对角） | Ch9 阻抗/导纳共用（阻抗 `K_d/D_d/M_d`、导纳 `K_a/D_a/M_a` 均映射到本类） |

**纯函数**：`clamp_to_limits(targets, limits) -> ndarray` —— 运动指令下发前的"软防护"共享底层。

### `transforms.py` —— 纯数学【Ch2.2 即用】

> 旋转矩阵、欧拉角/RPY、轴角、四元数、齐次变换矩阵的互转与运算。统一了 `chapt2_T_demo.py`/`chapt2_pose_demo.py` 中各自重复且乘法顺序不一致的实现（那两个一次性脚本保持原样不动，本模块供后续脚本复用）。

**统一约定**（写进模块 docstring）：

- `R`：`(3,3)` numpy，右手系。
- RPY：三合一 `rpy = (r, p, y)`，弧度；**默认 `R = Rz(y)·Ry(p)·Rx(r)`**（外旋固定角 X-Y-Z，与 `chapt2_fkine.md` §2.1.3 一致）。
- 四元数：`(w, x, y, z)`，实部在前。
- 齐次变换 `T`：`(4,4)`。

**函数清单**：

| 分类 | 函数 |
|:--|:--|
| 基本旋转 | `rot_x(a)`, `rot_y(a)`, `rot_z(a)` |
| RPY | `rpy_to_R(rpy)`, `R_to_rpy(R) -> (r,p,y)` |
| 轴角 | `rodrigues(k,theta=None)`, `R_to_axis_angle(R)`, `axis_angle_to_R(k,theta)` |
| 四元数 | `quat_to_R(q)`, `R_to_quat(R)`, `quat_to_axis_angle`, `axis_angle_to_quat`, `rpy_to_quat`, `quat_to_rpy`, `quat_mul`, `quat_conj`, `quat_norm` |
| 齐次变换 | `make_T(R,p)`, `T_to_Rp(T)`, `T_inv(T)`, `T_mul(T1,T2)`, `adT(T)` (6×6 伴随) |
| 插值 | `slerp(R0,R1,s)` (基于四元数，Ch5/Ch12 用) |

## 四、`arm/` —— 设备模型层

> 与 `backends/` 平行：设备模型（`Arm`/`Gripper`）包装对应通信后端（`ArmBackend`/`EndBackend`），把业务语义翻译为底层 CAN 收发。

### `arm.py` —— `Arm` 基类（组合根）【Ch2.2 即用】

> 依赖：`pinocchio`、`numpy`、`utils.types`。`ArmBackend` 抽象见 §`backends/`，`Arm` 仅持有其引用。

**实例属性**：

| 属性 | 类型 | 说明 |
|:--|:--|:--|
| `model` / `data` | `pin.Model` / `pin.Data` | pinocchio 模型与可复用缓冲区 |
| `n` | `int` | 自由度数（= nv） |
| `backend` | `ArmBackend \| None` | 真机后端；`None` = 离线模式 |
| `qlow / qhigh` | `ndarray(n,)` | 关节角软限位（= `joint_limits_soft.q_min/q_max`） |
| `q_neutral` | `ndarray(n,)` | 中性位形（pinocchio `neutral`，**非 home**） |
| `ee_frame_name` / `ee_frame_id` | `str` / `int` | 末端帧名（默认 `"ee"`）/ model 中索引 |
| `joint_limits` | `JointLimits` | 硬限位（URDF/电机极限） |
| `joint_limits_soft` | `JointLimits` | 软限位（略窄，留余量） |
| `tcp_limits` | `TcpLimits` | 末端限位 |
| `name` | `str` | 机械臂名称 |
| `T_base` | `ndarray(4,4)` | 基坐标系偏移（默认单位阵） |

**构造**：

```python
def __init__(self, urdf_path: str, backend: ArmBackend | None = None,
             ee_frame_name="ee", mesh_dirs=None, load_geometry=False, name="Arm"):
    """从 URDF 构建模型；解析关节限位；定位末端帧。backend=None 为离线模式。"""
```

**方法**：

| 方法签名 | 说明 | 需 backend |
|:--|:--|:--:|
| `rand_q(size=None, rng=None) -> ndarray` | 软限位内均匀采样；`size=int`→`(size,n)` | 否 |
| `clamp_q(q) / is_q_valid(q)` | 裁剪到 / 判断是否在软限位内 | 否 |
| `frame_placement(q, frame=None) -> ndarray(4,4)` | 底层单次 FK，返回 T | 否 |
| `fkine(q, frame=None, rep="T", method="auto")` | 薄委托 `robotics.fkine` | 否 |
| `ikine(T, q0=None, method="auto", ...)` | 薄委托 `robotics.ikine` | 否 |
| `jac(q, frame=None, ref="local", method="auto")` | 薄委托 `robotics.jacobian` | 否 |
| `fdyn(q, dq, tau, method="auto", ...) / idyn(q, dq, ddq, ...)` | 薄委托 `robotics.dyn` | 否 |
| `get_state() -> ArmState` | 委托 `backend.read_state()` | **是** |
| `command(q=None, dq=None, tau=None, kp=None, kd=None, mode=ControlMode.POSITION) -> None` | 按 mode 委托 backend 下发（见编码约定·控制模式） | **是** |

### `joyarm_rebot_dm.py` —— `JoyArmRebotDM(Arm)`【Ch2.2 即用】

> 固化 JoyArm（reBot-DevArm）特有默认值。型号扩展：新增型号继承本类覆盖类常量，再在 `load_arm()` 注册表登记一行。

**类常量**：

| 属性 | 值 |
|:--|:--|
| `DEFAULT_URDF` | `"robots/reBot-DevArm_fixend/urdf/reBot-DevArm_fixend.urdf"`（随包解析；过渡型号，第七章导出正式版 `joyarm1.urdf`） |
| `EE_FRAME` | `"end_link"` |
| `N_DOF` | `6` |
| `MDH_TABLE` | 6 行 MDH 参数（α,a,d,θ 偏移），**教学参考常量**（FK 仍走 pinocchio） |
| `Q_HOME` | home 位形 `(6,)`（实际 home，与中性位形未必相同） |

```python
def __init__(self, urdf_path: str | None = None, ee_frame_name: str | None = None,
             mesh_dirs: list[str] | None = None, backend: ArmBackend | None = None,
             load_geometry: bool = False, name: str = "JoyArmRebotDM"):
    """urdf_path 缺省时用 importlib.resources 解析随包 DEFAULT_URDF。"""
```

属性：`mdh_table`（property，返回 MDH ndarray）、`tcp_offset`（末端工具偏移 T，默认单位阵）。

> 文件名 `arm/joyarm_rebot_dm.py` = 型号 `joyarm_rebot_dm` = 类 `JoyArmRebotDM`。区别于通信层 `joyarm_rebot_dm_backend.py`（`JoyArmRebotDMBackend`，CAN 收发）。

> 与 `Arm` 同属设备模型层，依赖末端执行器通信后端 `EndBackend`（具体 `GripperBackend` 见 §`backends/`）。

| 方法签名 | 说明 |
|:--|:--|
| `class Gripper` | 两指夹爪：`__init__(backend: EndBackend, gripper_id=...)` |

## 五、`robotics/` —— 算法层

> 仅依赖 `utils` + numpy。核心算法统一支持 `method="auto"`（黑盒）/`"manual"`（白盒，先占位），见编码约定。

### `fkine.py` —— 正运动学【Ch2.2 即用】

| 函数签名 | 说明 |
|:--|:--|
| `fkine(arm, q, frame=None, rep="T", method="auto") -> ndarray` | 形状重载：`q=(n,)`→`T(4,4)`/`pos(3,)`；`q=(N,n)`→`(N,4,4)`/`(N,3)`。`rep`：`"T"`/`"pos"`/`"se3"` |

### `ikine.py` —— 逆运动学【Ch3 规划】

| 函数签名 | 说明 |
|:--|:--|
| `ikine(arm, T_target, q0=None, frame=None, tol=1e-4, iters=200, method="auto") -> IKResult` | 数值 LM 解（`auto`） |
| `ikine_constrained(arm, T_target, q0=None, ...) -> IKResult` | 带关节限位约束版 |

### `jacobian.py` —— 速度运动学与静力学【Ch4 规划】

| 函数签名 | 说明 |
|:--|:--|
| `jac(arm, q, frame=None, ref="local", method="auto") -> ndarray(6,n)` | `ref`：`"local"`(body)/`"world"` |
| `manipulability(arm, q, frame=None) -> float` | Yoshikawa 可操作度 |
| `cond_number(arm, q, frame=None) -> float` | 雅可比条件数（椭球分析） |
| `statics(arm, q, F, frame=None) -> ndarray(n,)` | 静力学 `τ = Jᵀ F` |

### `dyn.py` —— 动力学【Ch8 规划】

> 本库**不做物理仿真**（无 SimBackend）。`fdyn` 仅作"给定力矩求加速度"的数学函数（教学推导、控制律设计）；整机"仿真感"由 meshcat 可视化 + 轨迹预演呈现。

| 函数签名 | 说明 |
|:--|:--|
| `fdyn(arm, q, dq, tau, f_ext=None, method="auto") -> ndarray(n,)` | 正动力学：状态+力矩→加速度（pin.aba） |

### `trajectory.py` —— 轨迹生成【Ch5 规划】

> 关节/笛卡尔空间平滑轨迹，供 `control` 回放或 `viz` 预演（纯计算，不依赖 backend）。

**数据结构**：`Trajectory`（`space: TrajectorySpace`, `t: ndarray(K,)`, `q: ndarray(K,n)` 或 `poses: list[Pose]`, `metadata: dict`）+ `save(path)/load(path)` npz 持久化（示教回放/Ch12 复用）。

| 函数签名 | 说明 |
|:--|:--|
| `joint_cubic(q0, qf, T, hz=200)` / `joint_quintic(q0, qf, T, hz=200, v0=0, vf=0, a0=0, af=0)` / `joint_lspb(q0, qf, T, hz=200, v=None)` | 关节空间：三次/五次多项式/LSPB |
| `joint_waypoints(qs, Ts, *, smooth=True) -> Trajectory` | 多点途经：段间五次平滑拼接 |
| `cart_line(T0, Tf, T, hz=200)` / `cart_arc(center, radius, T_start, angle, plane="xy", T, hz=200)` | 笛卡尔直线（位置线性+姿态 slerp）/ 圆弧 |
| `cart_to_joint(arm, cart_traj, q0=None, method="auto") -> Trajectory` | 笛卡尔→关节（逐点 IK，处理奇异/不可达/多解） |
| `constant_velocity_retime(traj, v_max) -> Trajectory` | 按最大速度重定时 |
| `validate(traj, arm) -> list[Violation]` | 轨迹校验：途经点超限位/奇异（接 safety） |

### `control.py` —— 控制【Ch6/8/9 规划】

| `arm_position_control(arm, T_target, q0=None, method="auto")` / `arm_velocity_control(arm, twist_target)` | 整机：IK→关节角 / Jacobian→关节速度 |
| `class ControlLoop` | 实时循环 `start(hz)/stop()`，每 tick 读状态→策略→下发；消费 Ch5 轨迹 |

|:--|:--|

**Part 3 力控制【Ch9】**：

| 函数/类签名 | 说明 |
|:--|:--|

| `class JointTorqueSensor` | 关节力矩反馈（无力传感器分支主源）：`read()->ndarray(n,)` |

| `class AdmittanceControl` | 导纳：积分 `M_a ẍ + D_a ẋ + K_a(x−x_0) = F_ext` → Δx → 喂位置内环；参数 `K_a/D_a/M_a`=`ComplianceParams` |

## 八、`backends/` —— 通信层（仅真机）

> 按「机械臂本体 / 末端执行器」拆两条**独立**抽象（`ArmBackend`/`EndBackend`），互不继承——新增灵巧手/吸附等末端时不污染机械臂通信。

### `arm_backend.py` —— `ArmBackend` 抽象基类【Ch2.2 即用】

仅负责机械臂本体（6 关节电机，ID `0x01~0x06`）。

| 方法签名 | 说明 |
|:--|:--|
| `connect() / disconnect()` | 建立/断开通信（USB-CAN） |
| `enable(joint=None) / disable(joint=None)` | 使能/失能（默认失能） |
| `read_state() -> ArmState` | 完整状态快照 |
| `send_position(q, joint=None)` / `send_velocity(dq, joint=None)` / `send_torque(tau, joint=None)` | 位置/速度/力矩指令 |
| `send_mit(q, dq, tau_ff, kp, kd, joint=None)` | MIT 阻抗/前馈：`τ = kp·(q_des−q) + kd·(dq_des−dq) + tau_ff` |
| `set_zero(joint=None)` / `scan() -> list[int]` | 零位标定 / 总线扫描电机 ID |

### `end_backend.py` —— `EndBackend` 抽象基类【Ch2.2 即用】

仅负责末端执行器；`send_action`/`send_position`/`send_force` 覆盖离散动作/位置/力度三类需求。

| 方法签名 | 说明 |
|:--|:--|
| `connect() / disconnect()` | 建立/断开通信 |
| `read_state() -> dict` | 状态快照（字段由子类定义，如夹爪 `{"width_mm","force_N","is_grasping"}`） |
| `send_position(position)` / `send_force(force)` | 位置/力度控制（语义由子类约定） |
| `send_action(action)` | 通用离散动作（`"open"`/`"close"`；子类可扩展） |

### `joyarm_rebot_dm_backend.py`【Ch6 占位】 / `gripper_backend.py`【Ch13 占位】

- `JoyArmRebotDMBackend(ArmBackend)`：封装 JoyArm SDK（CAN，ID `0x01~0x06`）；当前仅占位。
- `GripperBackend(EndBackend)`：两指夹爪 CAN 通信（ID `0x07`）；是 `Gripper`（§四）的通信载体；当前仅占位。

```
      ↓

```
