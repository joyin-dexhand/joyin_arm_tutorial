# `joyarm/` 全篇架构设计方案（第 2~15 章）

> 角色：软件/系统架构师。
>
> 目标：把 `joyarm/` 设计成覆盖全教程（运动学 → 动力学 → 轨迹生成 → 运动控制+力控 → 安全 → 末端执行器 → 示教遥操 → ROS2、视觉）的**长期维护、可复用、最小化**核心 SDK 库。
>
> 本文档为**架构定稿**：仅确定模块边界、接口签名与依赖关系，**不写业务实现**。业务代码按章节顺序逐步落地（见 §十七 落地优先级）。

---

## 一、设计目标与原则

| # | 原则 | 落地体现 |
|:--:|:--|:--|
| 1 | **分层解耦** | 数学层 → 运动学模型层 → 动力学层 → 轨迹层 → 控制层 → 安全层 → 应用支撑层 → 可视化 → 适配器；下层不依赖上层 |
| 2 | **库 = SDK，被调用** | `joyarm` 只提供可被复用的库能力；CLI、上位机 GUI、综合任务编排等**前端与编排逻辑移入同级 `joyarm_code/quickstart/`**（见 §十五 交互方式与库边界） |
| 3 | **`Arm` 作为组合根** | `Arm` 持有 `model` + `backend`（可选）+ 限位，被 Ch5~Ch14 全部上层引用 |
| 4 | **Backend 仅真机** | `Backend` = 真机通信层（机械臂 `ArmBackend` / 末端执行器 `EndBackend` 两条独立抽象，唯一机械臂实现 `JoyArmRebotDMBackend`、夹爪实现 `GripperBackend`）；**不设物理仿真后端**；仿真/预演/教学场景走 `Arm(backend=None)` 离线模式 + meshcat 运动学可视化 |
| 5 | **型号与通信正交** | 不同机械臂型号（`joyarm_rebot_dm`…）= `Arm` 子类（各自 URDF/限位/home）；通信 = backend 实例；二者在 `load_arm(model=, backend=)` 工厂正交组合 |
| 6 | **双版本统一约定** | 核心算法（fkine/ikine/jacobian/dyn）单函数 + `method` 参数：`'auto'`=调 pinocchio 黑盒（应用版），`'manual'`=手写白盒（原理版，先占位）；文档讲解切 `method` 即对应"两种讲法" |
| 7 | **形状重载优先** | `fkine` 等通过输入形状自动切换批量/非批量，无需单独的 `*_batch` 函数 |
| 8 | **共享类型只定义一次** | `Wrench/Twist/Pose/ArmState` 等跨章复用，杜绝各模块重复定义 |
| 9 | **核心轻依赖** | 核心层仅依赖 numpy + dataclasses；ROS2/PySide6/VLM/VR/ASR 等重依赖作为可选适配器 |
| 10 | **函数式为主** | 求解器为模块级普通函数；类（Arm/JoyArm/Gripper/Sensor）作载体 + 薄委托方法 |
| 11 | **渐进式落地** | 每模块标注「Ch2.2 即用」或「ChN 规划」，接口先固化、实现后补；占位模块用 `raise NotImplementedError("ChN 实现")` |
| 12 | **类型 + 文档完备** | 所有公开 API 用 numpy shape 注释 + 中文 docstring，便于长期维护 |
| 13 | **零状态污染** | 模块级函数无全局可变状态；`Arm` 仅持有 `model`/`data`，调用方控制 `data` 复用 |

## 二、分层架构总览

```
┌─────────────────────────────────────────────────────────┐
│  application/  上层应用                                          │
│    可视化 viz.py(Ch2.2) · 遥操作 teleop.py(Ch12)                │
│    适配器 ros2.py(Ch10) · vision.py(Ch14)                       │
├─────────────────────────────────────────────────────────┤
│  safety/       安全层：safety.py(Ch11)                         │
├─────────────────────────────────────────────────────────┤
│  robotics/     算法层                                           │
│    control.py(Ch6/8/9) · trajectory.py(Ch5) · dyn.py(Ch8)      │
│    fkine.py(Ch2.2) · ikine.py(Ch3) · jacobian.py(Ch4)          │
├─────────────────────────────────────────────────────────┤
│  arm/          设备模型层                                       │
│    arm.py · joyarm_rebot_dm.py · gripper.py(Ch13)              │
├─────────────────────────────────────────────────────────┤
│  backends/     通信层                                           │
│    arm_backend · joyarm_rebot_dm_backend · end_backend · gripper_backend │
├─────────────────────────────────────────────────────────┤
│  utils/        基础层：transforms.py(数学) · types.py(共享类型) │
└─────────────────────────────────────────────────────────┘
```

**依赖方向**：仅允许向下依赖。`utils/`（`types`/`transforms`）处最底层、零机器人学耦合，可被 `joyarm_code/chapt` 教学脚本单独复用。

**横切**：`types`（共享数据类型）与 `viz`（可视化）不属于严格分层，被多层共用。

## 四、横切层：`utils/types.py` —— 共享数据类型（精简版）

> **职责**：全篇复用的不可变数据类型（`@dataclass`）与枚举（`enum`）。所有模块引用这里定义的类型，杜绝重复。
>
> **仅依赖** numpy + stdlib。

### 枚举

| 枚举 | 取值 | 用途 |
|:--|:--|:--|
| `ControlMode` | `POSITION / VELOCITY / TORQUE / MIT` | Ch6 控制模式（§6.1） |
| `Severity` | `INFO / WARNING / ERROR / CRITICAL` | Ch11 安全违规分级 |
| `SafetyAction` | `NONE / CLAMP / DAMPING_HOLD / FREEZE / ESTOP` | Ch11 响应策略 |
| `TrajectorySpace` | `JOINT / CARTESIAN` | Ch5 轨迹空间标识 |

### 数据类（dataclass）

| 类 | 字段 | 用途 |
|:--|:--|:--|
| `Wrench` | `force: ndarray(3,)`, `torque: ndarray(3,)` | Ch9 力控、Ch11 TcpState、Ch12 共用 |
| `Twist` | `linear: ndarray(3,)`, `angular: ndarray(3,)` | Ch4 速度、Ch12 笛卡尔遥操 |
| `Pose` | `T: ndarray(4,4)`（或 `R, p` 分量） | 统一位姿表示 |
| `JointState` | `q, dq, ddq, tau: ndarray(n,)`; `status: ndarray[int](n,)`; `temp_coil: ndarray(n,)`; `temp_driver: ndarray(n,)`; `voltage, current: float` | Ch11.1 关节层（位置/速度/加速度/力矩/**状态码**/**线圈温度**/**驱动器温度**/电压电流）；`status` 为关节电机状态码（0=失能，1=使能，其他值代表过温/过流/通信/等信息） |
| `TcpState` | `pose: Pose`, `twist: Twist`, `wrench: Wrench` | Ch11.2 末端层 |
| `ArmState` | `joint: JointState`, `tcp: TcpState`, `mode: ControlMode`, `timestamp: float`, `errors: list` | Ch11 聚合快照，监控器/示教/力控都消费它 |
| `JointLimits` | `q_min/max, dq_max, ddq_max, tau_max, temp_coil_max, temp_driver_max, voltage_min/max, current_max: ndarray(n,)` | Ch11.1 限位声明（含线圈/驱动器温度上限，对应 `JointState.temp_coil/temp_driver`）；实例化为 `Arm.joint_limits`（**硬限位**）/ `Arm.joint_limits_soft`（**软限位**，`q_min/q_max` 即 `qlow/qhigh` 略窄于硬限位） |
| `TcpLimits` | `workspace_box: ndarray(3,2)`, `v_lin_max, v_ang_max, f_max, t_max: float` | Ch11.2 末端限位 |
| `Violation` | `layer, joint_idx, metric, value, limit, severity` | Ch11 监控器输出；`layer` 标注监控层（关节/末端/整机，对应 §11.1/11.2/11.3），`severity` 为 `Severity` 枚举分级 |
| `IKResult` | `q, success, err, n_iter` | Ch3 逆解结果 |
| `ComplianceParams` | `K, D, M`（6×6 笛卡尔，默认对角） | Ch9 阻抗/导纳共用刚度/阻尼/惯量参数；阻抗 `K_d/D_d/M_d`、导纳 `K_a/D_a/M_a` 均映射到本类 `K/D/M` |

### 纯函数

| 函数 | 说明 |
|:--|:--|
| `clamp_to_limits(targets, limits) -> ndarray` | 所有运动指令下发前都要过它，是"软防护"的共享底层 |

## 五、Layer 0：`utils/transforms.py` —— 纯数学（零外部依赖，仅 numpy）

> **职责**：旋转矩阵、欧拉角/RPY、轴角、四元数、齐次变换矩阵的互转与运算。
> **来源**：`joyarm_code/chapt/chapt2_T_demo.py`、`chapt2_pose_demo.py` 当前各自重复且**乘法顺序不一致**（潜在 bug）——本模块统一约定并消除重复。
> **约定**：`chapt2_T_demo.py` / `chapt2_pose_demo.py` 作为一次性教学脚本**保持原样不改动**；本模块仅供后续新脚本（如 `chapt2_workspace.py`）复用。

### 统一约定（写进模块 docstring）

- 旋转矩阵 `R`：`(3,3)` numpy 数组，右手系。
- RPY 角：以**三合一数组 `rpy = (r, p, y)`** 传入（roll/pitch/yaw），弧度；**默认 `R = Rz(y)·Ry(p)·Rx(r)`**，与 `chapter2_2.md` **§2.1.3 外旋固定角（X-Y-Z，即 RPY）** 一致。
- 四元数：`(w, x, y, z)` 顺序，实部在前。
- 齐次变换 `T`：`(4,4)`。

### 函数清单（普通函数）

| 分类 | 函数 |
|:--|:--|
| 基本旋转 | `rot_x(a)`, `rot_y(a)`, `rot_z(a)` |
| RPY | `rpy_to_R(rpy)`（`rpy=(r,p,y)` 三合一）, `R_to_rpy(R) -> (r,p,y)` |
| 轴角 | `rodrigues(k,theta=None)`, `R_to_axis_angle(R)`, `axis_angle_to_R(k,theta)` |
| 四元数 | `quat_to_R(q)`, `R_to_quat(R)`, `quat_to_axis_angle(q)`, `axis_angle_to_quat(k,theta)`, `rpy_to_quat`, `quat_to_rpy`, `quat_mul`, `quat_conj`, `quat_norm` |
| 齐次变换 | `make_T(R,p)`, `T_to_Rp(T)`, `T_inv(T)`, `T_mul(T1,T2)`, `adT(T)` (6×6 伴随) |
| 插值 | `slerp(R0,R1,s)` (基于四元数，Ch5/Ch12 用) |

## 六、Layer 1：运动学模型层

### 6.1 `arm/arm.py` —— `Arm` 基类（组合根）+ `ArmBackend` 类型引用

> **依赖**：`pinocchio`、`numpy`、`types`。

#### 抽象基类 `ArmBackend`（见 §十三 `backends/`）

`ArmBackend` 抽象定义在 `backends/arm_backend.py`，`Arm` 仅持有其引用。接口见 §十三。

#### 类 `Arm` —— 持有 model + backend（可选）+ 限位

**实例属性**：

| 属性 | 类型 | 说明 |
|:--|:--|:--|
| `model` | `pin.Model` | pinocchio 运动学/动力学模型 |
| `data` | `pin.Data` | 数据缓冲区（可复用） |
| `n` | `int` | 自由度数（= nv） |
| `backend` | `ArmBackend \| None` | 机械臂真机后端实例；`None` = 离线模式（仅计算+可视化，不可下发执行） |
| `qlow / qhigh` | `ndarray(n,)` | 关节角**软限位**（弧度，略窄于硬限位、留余量）——供 `rand_q/clamp_q/is_q_valid` 运行时裁剪；**§5.2.1 表格直接用** |
| `q_neutral` | `ndarray(n,)` | 中性位形（pinocchio `neutral`，**非 home**） |
| `ee_frame_name` | `str` | 末端参考帧名（默认 `"ee"`） |
| `ee_frame_id` | `int` | 末端帧在 model 中的索引 |
| `joint_limits` | `JointLimits` | Ch11 完整**硬限位**声明（URDF/电机物理极限）；`q_min/q_max` 为位置硬限位，供 `safety.joint_limits_check` 监测报警（硬限位违规→ERROR/CRITICAL） |
| `joint_limits_soft` | `JointLimits` | **软限位**声明（略窄于硬限位、留余量）；其 `q_min/q_max` 即下文 `qlow/qhigh`，供 `rand_q/clamp_q/is_q_valid` 运行时裁剪（软限位违规→`SafetyAction.CLAMP`） |
| `tcp_limits` | `TcpLimits` | Ch11 末端限位 |
| `name` | `str` | 机械臂名称 |
| `T_base` | `ndarray(4,4)` | 基坐标系偏移（默认单位阵） |

**构造函数**：

```python
def __init__(self, urdf_path: str, backend: ArmBackend | None = None,
             ee_frame_name="ee", mesh_dirs=None, load_geometry=False, name="Arm"):
    """从 URDF 构建模型；解析关节限位；定位末端帧。backend=None 为离线模式。"""
```

**方法**：

| 方法签名 | 说明 | 是否依赖 backend |
|:--|:--|:--:|
| `__repr__() -> str` | 含 name/n/ee_frame 信息 | 否 |
| `rand_q(size=None, rng=None) -> ndarray` | 在**软限位**内均匀采样；`size=int`→`(size,n)`，用于工作空间 | 否 |
| `clamp_q(q) -> ndarray` | 将关节角裁剪到**软限位**内 | 否 |
| `is_q_valid(q) -> bool` | 关节角是否在**软限位**内 | 否 |
| `frame_placement(q, frame=None) -> ndarray(4,4)` | 底层：单次 FK，返回 T（numpy） | 否 |
| `fkine(q, frame=None, rep="T", method="auto")` | 薄委托 `fkine.fkine(self, q, ...)` | 否 |
| `ikine(T, q0=None, method="auto", ...)` | 薄委托 `ikine.ikine(self, T, ...)` | 否 |
| `jac(q, frame=None, ref="local", method="auto")` | 薄委托 `jacobian.jac(self, q, ...)` | 否 |
| `fdyn(q, dq, tau, method="auto", ...)` | 薄委托 `dyn.fdyn(self, q, dq, tau)` | 否 |
| `idyn(q, dq, ddq, method="auto", ...)` | 薄委托 `dyn.idyn(self, q, dq, ddq)` | 否 |
| `get_state() -> ArmState` | 委托 `backend.read_state()` | **是**（backend=None 时 raise RuntimeError） |
| `command(q=None, dq=None, tau=None, kp=None, kd=None, mode=ControlMode.POSITION) -> None` | 按模式委托 backend 下发：POSITION 用 `q`；VELOCITY 用 `dq`；TORQUE 用 `tau`；**MIT 用 `q,dq,tau(前馈),kp,kd`**（`τ = kp·(q_des−q) + kd·(dq_des−dq) + tau_ff`） | **是**（backend=None 时 raise RuntimeError） |

> **离线模式（backend=None）语义**：计算类方法（fkine/jac/frame_placement/trajectory 规划/dyn）不依赖 backend，无硬件也能跑（教学/工作空间绘制/轨迹预演）；执行类方法（command/get_state/control 下发）在 `backend=None` 时 `raise RuntimeError("离线模式不可执行")`。这是 Ch2.2 工作空间场景能轻量跑起来的前提。

### 6.2 `arm/joyarm_rebot_dm.py` —— 具体机械臂 `JoyArmRebotDM(Arm)`

> **职责**：固化 JoyArm（reBot-DevArm 硬件平台）特有默认值（URDF 路径、末端帧、MDH 参考表、home 位形）。
> **型号扩展**：当前仅落地 `joyarm_rebot_dm` 一个型号；未来新增型号只需继承 `JoyArmRebotDM` 并覆盖类常量（URDF/限位/home/MDH 表），再在 `load_arm()` 注册表登记一行；与 backend 正交（见 §十五）。

**类属性（常量，joyarm_rebot_dm 预设）**：

| 属性 | 值 |
|:--|:--|
| `DEFAULT_URDF` | `"robots/reBot-DevArm_fixend/urdf/reBot-DevArm_fixend.urdf"`（随包解析；过渡型号，第七章导出正式版 `joyarm1.urdf`） |
| `EE_FRAME` | `"end_link"`（与 §4.3.2 一致） |
| `N_DOF` | `6` |
| `MDH_TABLE` | JoyArm 6 行 MDH 参数（α,a,d,θ 偏移），作为**教学参考常量**（FK 仍走 pinocchio） |
| `Q_HOME` | 已知 home 位形 `(6,)`（**实际 home 位形，与中性位形未必相同**） |

**构造函数**：


## 十八、约定与规范

1. **numpy shape 约定**：关节角 `q` = `(n,)` 或批量 `(N,n)`；变换 `T` = `(4,4)`；批量 `T` = `(N,4,4)`；`Wrench/Twist` 内部 6 向量。
2. **角度单位**：内部一律**弧度**；GUI/文档展示需度时由调用方转换。
3. **返回值**：FK/IK 一律返回 **numpy**（非 `pin.SE3`），降低教学门槛；进阶可通过 `rep="se3"` 取原始对象。
4. **method 参数约定**：所有核心算法（fkine/ikine/jacobian/dyn）统一支持 `method="auto"`（黑盒，应用版）/ `"manual"`（白盒，原理版，先占位）。
5. **形状重载**：`fkine` 等按输入形状自动切换批量/非批量，不设单独 `*_batch` 函数。
6. **backend 语义**：`Backend` 仅真机；`Arm(backend=None)` = 离线模式（计算+可视化可用，执行类方法 raise RuntimeError）。
7. **型号正交**：型号差异 = `Arm` 子类；通信差异 = backend 实例；二者在 `load_arm(model=, backend=)` 正交组合。
8. **核心轻依赖**：`types/transforms` 仅 numpy+stdlib；ROS2/PySide6/VLM/VR/ASR 重依赖只进适配器或 quickstart。
9. **docstring**：每个公开函数/方法用中文 docstring，注明参数 shape、返回 shape、单位、约定、对应章节。
10. **错误处理**：URDF 缺失/帧名找不到/超限位/离线模式执行 → 明确异常（`ValueError`/`RuntimeError`）并附定位信息。
11. **软/硬限位分级**：`Arm.joint_limits_soft` 为**软限位**（`q_min/q_max` 即 `qlow/qhigh`，略窄、留余量），供 `rand_q/clamp_q/is_q_valid` 运行时裁剪，违规→`SafetyAction.CLAMP`；`Arm.joint_limits` 为**硬限位**（URDF/电机物理极限），供 `safety.joint_limits_check` 监测，违规→`Severity.ERROR/CRITICAL`。二者协同构成 Ch11 多层防护。
12. **控制模式约定**：`ControlMode` 四态——POSITION(`q`)/VELOCITY(`dq`)/TORQUE(`tau`)/**MIT(`q,dq,tau_ff,kp,kd`)**；`command` 按 mode 取对应参数，多余参数忽略；MIT 模式经 `Backend.send_mit` 下发（`τ = kp·(q_des−q) + kd·(dq_des−dq) + tau_ff`）。
