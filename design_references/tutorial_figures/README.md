# 教程配图视觉规范

本目录保存教程配图的内部参考，不属于 MkDocs 正文，也不会出现在站点导航中。

## 已确认风格

- 采用深炭黑背景、白灰色机械臂和干净的工程教材插画风格；
- 用青色表示关节、轴线或局部运动贡献，用橙色表示主要结果或合成运动；
- TCP 坐标系沿用红、绿、蓝三轴，姿态或运动辅助量可使用紫色；
- 减少装饰、纹理和发光效果，保证缩小后仍能辨认机械结构与箭头；
- 生成图不直接承担精确数学标注。关节轴、坐标系、箭头、文字和公式应在后期用 SVG 精确绘制；
- 最终机械臂外观以之后提供的 JoyArm 多视角照片、CAD 渲染图、URDF 截图或透明背景图为准。

## 后续制作输入

正式重绘前需要补充：

1. JoyArm 正面、侧面和斜视角的清晰参考；
2. 必须保持准确的关节轴、末端执行器和机身配色；
3. 每张图需要表达的单一知识点；
4. 章节结构确定后的最终插图位置和图注。

第四章当前所需插图及位置记录在 `docs/chapt4_jacobian.md` 的“配图占位”块中。
