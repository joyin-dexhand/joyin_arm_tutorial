# 第1章 机器人与机械臂初识

本章面向零基础读者，建立对机器人和机械臂的整体认知：了解其发展历史与分类，并速扫盲本教程涉及的核心基础概念。

## 1 发展历史与分类方式

一段话简单介绍机器人的泛历史。

一段话介绍机器人常见分类：工业机器人-服务机器人，移动机器人-固定机器人，海陆空天及跨质机器人。

一段话介绍机械臂：实用性最高、范围最广、最经典、是一些其他类型机器人的前置基础（如人型和四足）。

## 2 基础概念速扫盲

中英对照。为便于初学者建立整体认知，下面按类别给出本教程涉及的基础名词。

### 2.1 机械结构与几何类（本章重点建立直观认知）

机械臂、自由度、关节、连杆、末端执行器、负载、工作半径。

标准坐标系：基座系、连杆系、腕部系、末端系（工具系）、固定系（工作台系）、目标系（物体系）。

### 2.2 硬件与感知类

执行器（电机）、传感器（编码器、关节力矩传感器、六维力传感器、深度相机等）。

### 2.3 学科方法类（本教程主线，各章逐步展开）

位置运动学与逆运动学、速度运动学与雅可比、静力学、动力学、轨迹生成、运动控制、力控制。

### 2.4 开发工具与环境

ROS2、C++与 Python、AI Coding Agent。

开发环境（Ubuntu22 + conda + Python3.10 + VSCode）。

边缘计算设备（笔记本电脑、Jetson、RDK 等）。
