# 快速上手

> 📌 **本章定位**：无原理、公式，按照"拆箱验收 → 单电机设置与测试 → 整臂组装 → 上电初始化 → 运行实例例程"的操作流程快速将机械臂用起来。机械臂正逆运动学、动力学、规划控制等原理部分讲解，请前往[基础篇](chapt1_intro.md)、[进阶篇](chapt7_urdf.md)和[应用篇](chapt11_safety.md)。

## 1 操作安全须知（必读）

> ⚠️ **请在第一次上电前完整阅读本须知，操作不当可能损坏机械臂或造成人身伤害！**

| 序号 | 安全要求 | 说明 |
|:---:|:---:|:---:|
| 1 | **保持工作空间清空** | 运行期间机械臂工作半径内不得有人员与障碍物 |
| 2 | **先置零位再上电** | 先将机械臂调整至安全姿态（零位）再上电 |
| 3 | **上电后禁止强行扳动** | 上电后切勿强行扳动关节，可能会损坏关节电机 |
| 4 | **紧急情况立即断电** | 运行时出现异常现象立即按下急停或断开电源 |

> 注：建议使用支持远程遥控的直流无线遥控开关继电器更便捷地控制电源通断。

## 7 运行实例例程（待进一步更新：参考第二节视频）

### 7.1 环境准备（仅首次）

以下例程均在 `joyarm_code/` 目录下运行，首次使用请先完成环境准备：

```bash
cd ~
# 克隆本教程仓库（joyarm_code/ 是其中的配套代码库子目录，非独立仓库）
git clone https://github.com/joyin-dexhand/joyin_arm_tutorial.git
cd joyin_arm_tutorial/joyarm_code   # 进入配套代码库目录（后续所有例程命令均在此执行）
curl -LsSf https://astral.sh/uv/install.sh | sh # 若电脑未安装 uv 则先安装 uv，已安装则跳过
uv sync                    # 创建环境并安装全部依赖
source .venv/bin/activate  # 激活环境
```

> ⚠️ 真机例程运行前，请务必先阅读 §1 操作安全须知。

### 7.2 全部例程一览表

全部快速上手的示例程序均位于仓库 `joyarm_code/quick_start/` 目录，运行命令时需位于 `joyarm_code/` 目录下；所有例程的功能介绍和运行方式均位于对应代码文件头部的注释文档中。

例程分三组，定位各不相同，新手按 **01 → 09 →（11~16 按需）** 的顺序体验即可，21~24 仅在「接入新型号」时才需要：

| 分组 | 编号 | 定位与建议 | 前置 |
|:---:|:---:|:---|:---|
| A · 功能体验 | 01~09 | 从零跑通对象创建、真机连接、直通指令、FSM 运动、监视器、示教与抓取——快速上手主线，从 01 开始逐条体验 | 无（离线例程 01/05 可直接跑；真机例程需已组装上电的机械臂） |
| B · 算法域测试 | 11~16 | fkine/ikine/jacobian/dynamics/trajectory/control 六域离线测试分析，供学习各算法域行为时按需选读 | 建议先跑完 01、05 |
| C · 新型号接入 | 21~24 | config/URDF/backend/整机四件套创建与自检，仅接入新型号时使用 | 先完成 01；创建流程详见各文件夹 README（见下表说明列） |

**编号说明**：编号 10、17~20 为预留档位（防止日后插入新例程时全表重排），并非缺文件；表中省略即不存在对应脚本。

**占位符约定**：`[ ]` 方括号 = 可选参数（如 01 行 `[型号名]` 可省略，省略时进入交互选择）；`< >` 尖括号 = 须替换的占位符（如 `<型号>` 需换成实际型号名）。21/22/24 的 `--model` 与 23 的 `--backend` 均有缺省值（21/22/24 缺省 `rebot_arm_b601_dm`，23 缺省 `backend_rebot_arm_b601_dm`），检查现有型号时可直接省略参数。
