# 第八章 动力学及控制

> 📌 **概述**：本章讲解机械臂动力学及其在控制中的应用。动力学有两大作用：给力矩求状态的仿真 + 给状态求力矩的控制。本章对比拉格朗日法和牛顿欧拉法的计算效率，推导动力学方程的结构，并基于动力学效应实现机械臂控制。
