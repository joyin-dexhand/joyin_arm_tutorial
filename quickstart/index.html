    快速上手

    📌 本章定位：无原理、公式，按照"拆箱验收 → 单电机设置与测试 → 整臂组装 → 上电初始化 → 运行实例例程"的操作流程快速将机械臂用起来。机械臂正逆运动学、动力学、规划控制等原理部分讲解，请前往基础篇、进阶篇和应用篇。

    1 操作安全须知（必读）

    ⚠️ 请在第一次上电前完整阅读本须知，操作不当可能损坏机械臂或造成人身伤害！

    序号 安全要求 说明
    1 保持工作空间清空 运行期间机械臂工作半径内不得有人员与障碍物
    2 先置零位再上电 先将机械臂调整至安全姿态（零位）再上电
    3 上电后禁止强行扳动 上电后切勿强行扳动关节，可能会损坏关节电机
    4 紧急情况立即断电 运行时出现异常现象立即按下急停或断开电源

    注：建议使用支持远程遥控的直流无线遥控开关继电器更便捷地控制电源通断。

    2 快速上手流程

    步骤 操作内容 操作目的
    1 拆箱验收，核对物料清单 确保零件齐全、运输途中无损坏
    2 设置并调试关节电机 分配电机标识 ID、验证电机功能
    3 固定基座并组装电机与结构件 完成机械臂整臂的组装和固定
    4 机械臂摆放至零位进行标定（整机版出厂已标定），进行整臂调试 确定各关节电机零位基准并调试整臂
    5 运行实例例程代码，上手二次开发 熟悉并复现验证整臂的功能能力，熟悉代码库

    6.1 连接、上电与自检

    整机组装完成后，首次上电时须按规范流程操作并完成自检，确保各关节状态正常。

    整臂上电接线 + 上位机自检界面

    机械臂零位姿态

    步骤 操作内容 操作 操作演示图
    1 安装并启动上位机 便于测试和运动可视化 占位
    2 机械臂置于零位姿态 保持零位稳定姿态，防止发生意外移位 占位
    3 连接电源与通讯线 供电并建立通信链路 占位
    4 上位机扫描总线，识别全部电机 确认全部关节通信正常 占位
    5 读取电机状态 核对温度、电压、电流、故障码均正常 占位
    6 关节电机零位标定 通讯连接后通过上位机进行整臂的零位标定 占位

    📌 整臂版出厂已标零，可跳过该步；但拆卸重新组装或更换电机后需重新进行标零。

    7 运行实例例程（待进一步更新：参考第二节视频）

    7.1 环境准备（仅首次）

    以下例程均在 joyarm_code/ 目录下运行，首次使用请先完成环境准备：

    cd ~
git clone url # 拉取 joyarm_code 代码库至本地（强烈建议放在主文件夹根目录）
cd joyarm_code
curl -LsSf https://astral.sh/uv/install.sh | sh # 若电脑未安装 uv 则先安装 uv，已安装则跳过
uv sync                    # 创建 .venv 并按 uv.lock 安装全部依赖

    ⚠️ 真机例程运行前，请务必先阅读 §1 操作安全须知。

    7.2 全部例程一览表

    全部快速上手的示例程序均位于仓库 joyarm_code/quickstart/ 目录，运行命令时需位于 joyarm_code/ 目录下；所有例程的功能介绍和运行方式均位于对应代码文件头部的注释文档中。

    例程 运行条件 启动命令 说明
    01 离线模型与数学 离线 uv run python quickstart/01_offline_model.py 无需硬件：模型信息浏览 + 正逆运动学/雅可比/动力学求解与六域求解器切换
    02 连接与状态读取 真机 uv run python quickstart/02_connect_read.py 连接、使能与状态读取：两种状态口径、故障码与电机参数读取
    03 直接指令与夹爪 真机 uv run python quickstart/03_direct_command.py FSM 未运行时的直接指令：位置/速度/MIT 三模式与末端夹爪动作
    04 FSM关节与笛卡尔运动 真机 uv run python quickstart/04_fsm_motion.py 状态机闭环运动：关节/笛卡尔目标、TrajFrame 通道与安全事件切换
    05 监视器与可视化 真机 uv run python quickstart/05_monitor_viz.py 自定义安全监视规则与三栏实时可视化面板
    06 拖动示教与回放 真机 uv run python quickstart/06_teach_replay.py 阻尼态拖动示教录制轨迹并逐路点回放
    07 综合抓取 真机 uv run python quickstart/07_pick_demo.py 逆解 + FSM 运动 + 夹爪的完整抓取—放置闭环
